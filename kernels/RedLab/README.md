# COXVBN RedLab

RedLab 是基于 COXVBN 延伸的授权安全测试与隐私保护方向，独立维护其策略、工具适配、测试用例和文档。

## 边界

- 仅用于明确授权的安全评估、隔离实验、漏洞验证和审计。
- 普通隐私配置与安全测试模式分离，默认拒绝未授权操作。
- 不实现恶意持久化、隐蔽控制或规避检测能力。
- 与 COXVBN 共享底层内核能力时，通过稳定接口调用，不复制基础内核源码。

## 当前状态

此目录先建立项目边界与文档入口。当前 `main` 分支中尚无可独立启动的 RedLab 内核镜像；历史分支中出现过 RedLab 策略相关代码，但迁移前需要逐项核对依赖、接口和测试，不能把旧分支代码直接视为已集成实现。

后续 RedLab 专属源码、构建目标和测试应放在本目录下，并在完成迁移与 CI 验证后更新本说明。
